# 原仓库奶龙素材替换计划

用户明确指定复制 https://github.com/timerring/codex-pet-naiwa 中的角色，取代 v1.1.0 的手绘像素角色。沿用已确认的无声、点击大笑、结束回待机、横屏自适应和完全离线行为，不新增桌宠安装功能。

## 设计

- 原样复制 spritesheet.webp，固定源提交 3c0cd7ca231f02e0d4d6956fc6ce86eb9f0cfb50。
- 精灵表尺寸 1536×2288，每格 192×208。待机取第 0 行第 0 帧；捧腹大笑取第 4 行的 5 帧，避免把移动或招手动作当成大笑。
- Canvas 只裁取对应源帧显示，不改角色外观；保持宽高比，预留标题和安全区。
- 源图加载成功后可点击；失败时明确提示。完全离线 HTML 内嵌同一源图，PWA 缓存同一文件。
- 版本升至 v1.1.1，保留此前排版修复。源图不因本项目 MIT 而重新授权，保留 timerring 的原始许可及第三方素材说明。
