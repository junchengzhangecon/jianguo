# 排版修复与无声像素奶龙 Implementation Plan

**Goal:** 修复手机横屏像素字粘连，加入可离线点击大笑的像素奶龙，并推送 GitHub Pages。

**Architecture:** 新建独立的 display.js，负责原生整数倍字体排版和手绘像素角色。app.js 只负责状态与点击，构建脚本内联所有程序，保持单文件离线。

**Tech Stack:** 原生 Canvas / JavaScript，Node tests，Playwright / Chrome，GitHub Pages。

## 已确认的设计

- 文字保留 12px 字体的整数倍，不再缩成任意小字号；逐字增加间距，行间留白，整块等比适配视口。
- 工牌姓名比职位与补充信息更醒目；过长内容换行或明确提示，不将文字挤成一团。
- 新增“奶龙模式”：自绘黄色像素角色，点击或键盘激活后无声大笑约 2.4 秒，结束回到待机，可反复点击。非官方像素演绎，无外部视频素材或网络请求。
- 保持全屏、横竖屏、设置持久化和分享功能；角色模式隐藏无关文字设置。
- 更新缓存版本；v1.0 用户联网下载后需关闭该站全部旧窗口再打开，新提示仅适用于今后版本，不强制中断展示。发布 v1.1.0 离线文件，保留旧版下载。
