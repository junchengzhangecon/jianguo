# 防息屏与增强兼容实现计划

用户：坚果 Pro 3，自带浏览器；已设置系统常亮，但一段时间后变暗，内容仍可见。需要网页内可操作的选项。网页不能控制系统亮度、自动亮度、省电调光或硬件保护，不能承诺永不变暗。

## 设计

- 预览下面新增独立“防息屏／保持唤醒”面板：自动、增强兼容、关闭；保存为本机偏好，不随文字分享链接传播。
- 自动模式在前台优先申请标准 Screen Wake Lock；接口不可用时需用户点击触发无声视频保活。
- 增强兼容在用户手势内播放本地无声视频，同时在可用时申请标准接口。视频播放成功只显示“兼容保活播放中”，不等同于系统保证常亮。
- 前台恢复重新申请；意外释放有限次数退避重试，不无限对抗系统拒绝。切后台、关闭、离开页面时释放资源；并发请求和迟到的异步结果不能造成资源泄漏。
- 面板与全屏退出栏均显示真实状态和重试按钮，提示系统自动亮度、省电模式与系统限制。
- 视频素材沿用 NoSleep.js 的 MIT 许可本地短片，不加载 CDN；单文件 HTML 内嵌视频，离线仍可用。
- 版本 v1.2.0，推送现有 GitHub Pages 并发布新版离线文件。
