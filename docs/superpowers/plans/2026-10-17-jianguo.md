# 坚果像素屏 Implementation Plan

> **For agentic workers:** 使用当前会话顺序执行，独立评审辅助检查离线与兼容性；不修改已有学术网站。

**Goal:** 一个手机直接打开即可使用、支持离线的中文像素信息屏。

**Architecture:** 无框架静态网页。`core.js` 管配置和基于目标时间的计时，`app.js` 管编辑器及 Canvas 点阵显示。`sw.js` 缓存线上版；构建脚本将本地字体、CSS、JS内嵌生成单文件离线版。

**Tech Stack:** HTML/CSS/JavaScript、Canvas、Service Worker、Node 内置测试、Playwright。

## 文件职责

- `index.html`, `styles.css`：中文编辑器、响应式布局、展示模式。
- `core.js`：参数规范化、配置链接、倒计时状态机、时间格式。
- `app.js`：像素渲染、滚动、时钟/倒计时/番茄钟/状态/工牌、存储、常亮。
- `sw.js`, `manifest.webmanifest`, `assets/icon.svg`：离线缓存与安装元信息。
- `assets/pixel.woff2`, `LICENSES/`：离线字体及许可证。
- `scripts/build.mjs`：生成可发布文件夹与单文件离线 HTML。
- `tests/core.test.cjs`, `tests/browser.cjs`：计时状态边界和浏览器验收。
- `README.md`, `.nojekyll`：中文使用说明与 GitHub Pages 从 main 根目录自动发布。

## 评审补充

- 单文件必须断网实际编辑、切换滚动和运行计时，并确认没有外部请求；不使用 ES modules 或 file:// 下的 Service Worker。
- Canvas 等待字体显式加载后测量与重绘；检查首次断网单文件及离线输入新中文。
- 在 `/jianguo/` 下验证所有资源、配置链接、manifest与离线重开；缓存仅清理本项目名称前缀，不影响学术主页。
- 持久化截止时间、暂停剩余量、状态、番茄钟阶段；测试刷新/重开过期与暂停恢复，结束阶段停住不累计虚假轮数。存储禁用时明确说明限制。
- 手机横向摆放为主，按实际CSS视口自适应，展示画布避让刘海与圆角安全区，不写死硬件分辨率。

## 验收与限制

网页/PWA首次在线缓存后可离线；单文件初次打开不发网络请求。常亮/全屏是否可用取决于浏览器且需要用户手势。安卓文件管理器可能不允许本地HTML直接交给浏览器，此时使用已缓存的HTTPS版本。不承诺锁屏/系统强制杀进程时会发出提醒。不包含跨设备实时遥控。
