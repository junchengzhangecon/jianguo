# 坚果像素屏 · Jianguo Pixel Studio

把旧安卓手机变成像素信息屏。中文编辑、黑底点阵、可开关的滚动字幕、时钟、倒计时、番茄钟、工作状态、电子工牌和无声奶龙。横放展示优先，横竖屏均自适应；Mac 也能编辑预览。

## v1.2.0 更新：防息屏 / 保持唤醒

显示预览下面新增常亮面板，不必在浏览器菜单里找设置：

- **自动**：在本页前台时优先申请标准屏幕常亮。老浏览器不支持接口时，需点击“应用 / 重试”或“进入全屏展示”启动无声兼容保活。
- **增强兼容**：建议坚果 Pro 3 自带旧浏览器尝试。选择后点击“应用 / 重试”，播放本机无声短片，同时在可用时申请标准常亮。短片不遮挡内容、不联网，没有声音。
- **关闭**：停止视频并释放常亮请求，恢复系统正常的休眠策略。

状态栏会区分“标准常亮已取得”“兼容保活播放中”“需点击启动”“未生效”，不会只因用户选择了模式就宣布成功。兼容播放仅是尽力保活，实际防调暗效果需要在手机上确认。前台恢复会重新申请，意外释放最多自动重试两次；系统拒绝不会无限循环请求。

偏好保存在本机，不包含在分享链接中。退出全屏后，只要网页仍在前台，已开启的防息屏仍运行；切后台、离开页面或选择关闭时会释放资源。刷新后兼容视频可能需要再点一次启动。

**变暗不一定等于息屏。** 如果仍能看见内容，也请检查手机系统的自动亮度、省电模式；网页不能设置系统亮度、关闭系统省电策略或覆盖硬件保护调暗。常亮和兼容视频会增加耗电，避免长时间高亮静态展示，注意设备温度。

接口支持、安全上下文和系统拒绝限制见 [MDN Screen Wake Lock API](https://developer.mozilla.org/en-US/docs/Web/API/Screen_Wake_Lock_API)；兼容短片来源 [NoSleep.js](https://github.com/richtr/NoSleep.js)，已本地化并保留 MIT 许可，不依赖 CDN。单文件版已内嵌短片。

## 手机怎么用

### 网页版：首次联网，之后可离线

打开 https://junchengzhangecon.github.io/jianguo/ 。等左下角或页面底部出现“已准备好离线使用”，即可断网继续使用并重新打开。同一浏览器中可通过菜单“添加到主屏幕”保存入口。不要使用无痕模式，也不要清除该站点的数据。浏览器可能在存储空间紧张时清理缓存。

### 从第一次打开就断网：单文件版

把发布版本中的 `坚果像素屏-离线版.html` 通过 USB、蓝牙或文件传输复制到手机。在手机文件管理器中选择该文件，使用支持本地 HTML 的浏览器打开。文件已内嵌字体、样式、脚本，不需联网、不需安装程序、不需 Mac 开着。

不同安卓文件管理器的 HTML 打开方式不同：如果出现源码文本、禁止打开、或文件管理器预览不执行脚本，请改用“打开方式 → 浏览器”；若手机不允许这种方式，改用上面的已缓存网页版。主屏幕安装入口、全屏和自动常亮在 `file://` 下可能不可用。

单文件版字体采用 OFL-1.1；分发时请一并保留 `LICENSES/`（离线压缩包已包含）。

## 展示与设置

- 选择模式，修改内容、颜色和像素字号。文字模式可换行，静态长文自动适配，超长文建议滚动展示。
- 开启“滚动字幕”后可选方向和速度。关闭后居中静态显示。
- 横放手机，点击“进入全屏展示”。轻触屏幕显示退出按钮；电脑按 Esc 也可退出。
- 奶龙模式下点击预览或全屏里的角色即可大笑；该模式不受文字颜色、字号和滚动设置影响，退出后原文字设置仍然保留。
- 常亮请在预览下方的“防息屏 / 保持唤醒”面板选择；系统仍可因低电量、省电或后台策略拒绝或释放请求。刘海/圆角区域预留安全边距；没有强制锁屏幕方向，直接旋转手机即可。
- 倒计时/番茄钟支持开始、暂停、继续、重置。计时使用截止时间而非帧数；允许存储时可刷新或重开恢复。番茄钟到时停在当前阶段，手动进入下一阶段；关闭一晚不会自动累计许多轮。
- 提示音需在页面里点击开始后才可播放；锁屏、后台或浏览器被系统杀死时不保证响铃。这不是系统闹钟。
- 分享配置只导入一次，不会实时遥控手机。分享链接包括填写的文字，不能填写密码、令牌等秘密信息。本地版生成的分享链接指向线上项目，因此接收端首次打开需联网；彻底无网时请在手机直接编辑。
- 若浏览器禁用存储，页面仍可运行，但关闭后不保证恢复设置与计时。系统时间被调整时，倒计时也会受影响。

## 本地开发与发布

无需安装前端依赖，仅需 Node.js 22 或更新版本：

```sh
npm test
npm run build
npm start
```

在电脑打开 `http://localhost:4173`。局域网手机预览可打开 `http://电脑局域网IP:4173`，电脑需要开着；普通局域网 HTTP 通常不支持 Service Worker/PWA 缓存与 Wake Lock，离线请使用 HTTPS 或单文件版。

修改后先执行 `npm test` 和 `npm run build`，再将源码和根目录生成的 `坚果像素屏-离线版.html` 一起提交并推送 `main`。GitHub Pages 从 `main` 分支根目录发布，不需要自定义 Actions 工作流。字体与所有资源都在项目内，不依赖 CDN。应用支持 `/jianguo/` 子路径，SW 只清理本项目缓存。

更新需要递增 `sw.js` 的缓存版本。新版本在旧页面关闭后激活，重新打开时使用新资源。

浏览器回归测试（需可用的 Playwright 与 Chrome）位于 `tests/browser.cjs`、`tests/regressions.cjs`、`tests/update.cjs`、`tests/wake-browser.cjs`；可用 `JIANGUO_BROWSER_PATH` 指定浏览器，`JIANGUO_TEST_URL` 指向本地或 Pages 网址。`tests/upgrade.cjs` 验证旧缓存升级和设置保留，可用 `JIANGUO_UPGRADE_FROM` 指定旧版提交。`npm test` 运行计时、配置、像素排版及防息屏生命周期的单元测试。

## 真机验收

在坚果 Pro 3 的实际浏览器上检查：中文加载、横竖屏旋转、屏幕四边无截字、全屏退出、静态与滚动开关、休眠设置、离线重新打开、暂停后刷新恢复、倒计时结束。浏览器模拟不等于真机已验证。
